# CSVFilters SEO Content Plan

Generated: 2026-06-20

## Keyword clusters added

1. Large CSV opening
   - Primary: open large CSV file
   - Secondary: large CSV viewer, Excel cannot open CSV, CSV file too large, view large CSV
   - Search intent: user has a CSV that is too large for Excel and needs a safe viewer.

2. CSV to Excel
   - Primary: CSV to Excel
   - Secondary: convert CSV to XLSX, CSV to XLSX converter, CSV opens incorrectly in Excel, CSV leading zeros
   - Search intent: user wants Excel-friendly output without data corruption.

3. CSV merge/combine
   - Primary: combine CSV files
   - Secondary: merge CSV files, append CSV files, combine multiple CSV files, CSV merger
   - Search intent: user has many exports and wants one clean combined file.

4. CSV repair/validation
   - Primary: CSV repair
   - Secondary: CSV validator, fix CSV file, malformed CSV, CSV validation, CSV encoding issue
   - Search intent: user has a CSV that fails import or displays incorrectly.

5. CSV to JSON
   - Primary: CSV to JSON
   - Secondary: convert CSV to JSON, CSV to JSON converter, JSON Lines, NDJSON, API data import
   - Search intent: developer wants to convert tabular data into API-friendly JSON.

## Layout rules used

- Primary keyword appears in the page title, metadata title, introduction, and at least one H2-adjacent section.
- Secondary keywords appear in metadata keywords, the article header keyword chips, body sections, FAQ, and internal links.
- Each article includes a direct tool CTA so informational traffic can move into tool usage.
- FAQ sections cover long-tail searches and help pages qualify for richer search snippets.
- Related tutorials create internal links between overlapping CSV tasks.
